Privacy Policy for Tok Pisin ↔ English Translator

Last updated: September 2026

Tok Pisin ↔ English Translator translates between Tok Pisin and English entirely offline on the user's device.

Data Collection

We do not collect, store, transmit, sell, or share any user data. Translation input, translation output, and all extension state never leave the user's device. The extension makes no network requests at any time.

Permissions

  • offscreen: used to run the bundled Transformers.js and onnxruntime-web WebAssembly translation pipeline in a hidden offscreen document because Manifest V3 service workers cannot reliably run WebAssembly model inference directly. All inference happens locally.
  • storage: used to save a single local counter of how many times the popup has been opened, the user's chosen translation direction, and a one-time flag for the support message. All values are stored locally on the user's device.
  • clipboardRead: used only when the user clicks the Paste button in the popup, to read text the user has explicitly copied to their clipboard and insert it into the translation input field. Clipboard content is never read automatically, is never stored, and is never transmitted to any server.

Third Parties

None. No data is sent to external servers or third parties. No analytics, no tracking, no advertising.
